# Тлеющая Роща

Небольшой изометрический adventure-map prototype на Phaser + TypeScript + Vite.

## Запуск

```bash
npm install
npm run dev
```

Текущий dev server поднят на `http://127.0.0.1:5174/`.

## Управление

- `WASD` или стрелки: движение по карте
- `E` или `Space`: взаимодействие
- `N`: завершить день

## Что уже есть

- изометрическая карта с diamond-тайлами, глубиной, препятствиями, дорогами, водой и объектами
- динамический свет костра/святилища, shimmer воды, тени и depth-сортировка объектов
- цикл карты приключений: герой, запас хода, день, ресурсы, город, шахты и флаги захвата
- нейтральные стражи решаются автобоем на карте, без тактического боевого экрана
- NPC-квест у Старшей Миры
- сундуки, осколки, зелья
- XP, уровень, рост HP/атаки
- DOM HUD и журнал событий
- сохранение прогресса в `localStorage`
